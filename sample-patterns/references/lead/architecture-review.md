# Architecture Review Skill

Use for reviewing technical design and implementation approach.

Check:
- Fits existing architecture.
- Keeps business logic in appropriate layer.
- Avoids unnecessary abstraction.
- Handles validation and authorization.
- Handles errors and logging.
- Is testable.
- Is backward compatible.
- Has clear migration or rollout plan if needed.

Output:
- Approved / Needs changes
- Key concerns
- Required changes
- Risks
