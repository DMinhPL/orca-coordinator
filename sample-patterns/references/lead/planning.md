# Planning Skill

Use for feature planning, refactoring plans, bug-fix plans, and delivery breakdowns.

Checklist:
- Define objective.
- Identify scope and out-of-scope items.
- Identify affected modules.
- Split work into small tasks.
- Identify dependencies.
- Identify risks and assumptions.
- Define validation steps.

Output:
- Objective
- Scope
- Task breakdown
- Dependencies
- Risks
- Validation plan
