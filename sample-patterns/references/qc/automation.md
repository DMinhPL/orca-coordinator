# Automation Skill

Use for suggesting automated test coverage.

Consider:
- Unit tests for pure business rules.
- Integration tests for service/database flows.
- API tests for endpoints and contracts.
- E2E tests for critical user journeys.
- Snapshot tests only when stable and useful.

Rules:
- Automate critical repeatable flows.
- Avoid brittle tests.
- Reuse existing test helpers and factories.
- Keep tests deterministic.
