# Test Case Skill

Use for creating detailed manual or automated test cases.

Each test case should include:
- ID
- Title
- Priority
- Type
- Preconditions
- Test data
- Steps
- Expected result

Cover:
- Positive cases.
- Negative cases.
- Edge cases.
- Permission cases.
- Regression cases.

Rules:
- Expected result must be specific and verifiable.
- Keep each test case focused.
