# Regression Skill

Use for identifying existing behavior that may break after a change.

Checklist:
- Related modules.
- Shared services.
- Common UI components.
- API contracts.
- Database schema or query changes.
- Permission changes.
- Existing reports/exports.
- Background jobs.
- Third-party integrations.

Output:
- Regression areas.
- Recommended tests.
- Release blockers.
