# Test Strategy Skill

Use for deciding what and how to test.

Include:
- Test scope.
- Test levels: unit, integration, API, E2E, manual.
- Test data needs.
- Environments.
- Regression areas.
- Risks.
- Exit criteria.

Rules:
- Prioritize high-risk flows.
- Cover permissions and business rules.
- Recommend automation for repeatable critical flows.
