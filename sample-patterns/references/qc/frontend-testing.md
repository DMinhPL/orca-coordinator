# QC Frontend Testing

Load for UI/browser/Next.js/React/WebView work.

Check relevant areas:
- loading, empty, success, error states;
- repeated click/submit and race behavior;
- responsive overflow and long content;
- keyboard/focus/accessibility for interactive controls;
- refresh/back/forward/reconnect state;
- hydration/client-only behavior when applicable;
- storage/session identity separation;
- iframe/WebView postMessage origin/lifecycle;
- animation/media performance when the change affects rendering cost.
