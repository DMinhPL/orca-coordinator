# Acceptance Criteria Skill

Use for writing clear, testable acceptance criteria.

Preferred format:
Given [context]
When [action]
Then [expected result]

Checklist:
- Positive scenarios.
- Negative scenarios.
- Permission scenarios.
- Validation scenarios.
- Error scenarios.
- Data/state changes.
- UI/API expected output.

Rules:
- Criteria must be verifiable by QC.
- Avoid vague words.
- Include exact expected behavior.
