# User Story Skill

Use for writing user stories and feature behavior.

Format:
As a [user role],
I want [capability],
So that [business value].

Include:
- User role.
- Goal.
- Business value.
- Main flow.
- Alternative flows.
- Permission rules.
- Edge cases.

Rules:
- Keep stories small and testable.
- Avoid mixing multiple independent features in one story.
